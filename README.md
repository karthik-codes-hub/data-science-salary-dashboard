### 🔍 Dashboard Description

The dashboard provides an interactive view of salary and job-market trends using three main filters:

- **Job Title** – Compare salaries across different technology roles.
- **Country** – Analyze salary trends across different countries.
- **Employment Type** – Compare Full-time, Part-time, Contractor, Temp Work, and Internship roles.

The dashboard displays:

- 💰 **Median Salary** – Shows the median salary for the selected criteria.
- 🏢 **Top Job Platform** – Identifies the platform with the highest number of job postings.
- 📊 **Job Count** – Shows the total number of matching job postings.
- 📈 **Salary by Job Title** – Compares median salaries across roles.
- 🌍 **Country Map** – Provides a geographic view of the selected job market.
- 🕒 **Salary by Employment Type** – Compares salary levels across employment types.
